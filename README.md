# Coffee Date — Doodle Storyboard

Mobile-first, five-screen Mongolian coffee invitation inspired by the provided hand-drawn notebook storyboard.

## Included
- `index.html` — the five screens and UI structure
- `style.css` — notebook grid, pastel paper/cards, doodle illustrations and CSS animation
- `script.js` — playful escaping “Үгүй” button, day/time selection, confirmation, heart particles, back/restart navigation

## Run
Open `index.html` in a browser. No framework, build step, or install is required. Internet is only used to load Google Fonts; system fallbacks are included.

## Publish to GitHub Pages
1. Extract this ZIP.
2. Upload the three site files to the root of your repository, replacing the previous versions.
3. Commit the changes.
4. Open your GitHub Pages URL and hard-refresh with `Ctrl + F5`.

The illustrations are drawn with HTML/SVG/CSS rather than using the storyboard image as a flat background, so the controls remain interactive and responsive.
